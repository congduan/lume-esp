CAPABILITIES

A smaller stack. A direct path to pixels.

No C toolchain on the app author's machine. Declarative components, fine-grained signals, and board APIs share one compact JavaScript runtime.

↗

Iterate in JavaScript

The USB channel replaces the app runtime without rebuilding or reflashing firmware.

◇

UI that reacts

Signals update native LVGL attributes directly; flex, List, Image, and Canvas compose the screen.

⌁

Hardware within reach

GPIO, ADC, PMIC, IMU, storage, network, and audio APIs share one typed JS surface.

ARCHITECTURE

JavaScript on top. Native performance underneath.

LVGL stays strictly behind the bridge. Your app declares UI and hardware intent in plain JS while the C runtime batches mutations onto the panel.
