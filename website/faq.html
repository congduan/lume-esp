The useful caveats.

Read this before treating a code-complete feature as board-proven.

What are the resource limits?

The target board has 8 MB PSRAM and 16 MB flash per README. The type file caps a Canvas at 480×480 and a shared 460,800-byte RGB565 canvas budget. A single Fs.readBinary call is limited to 64 KiB. These are contract limits, not measured end-to-end app memory usage.

What has been tested on a real board?

The roadmap marks code and host-harness work separately from device acceptance. USB push latency, WiFi association and HTTP, audio playback and recording, sleep current and touch wake reliability, IMU readings, and display visuals still need on-device acceptance.

Is WiFi OTA or a host simulator available?

No. The CLI first slice pushes JavaScript source over USB. WiFi OTA and the host simulator remain open M4 items.
