PREREQUISITES

Prepare the board and CLI.

Use the Waveshare ESP32-S3-Touch-AMOLED-2.16 with Lume firmware installed. The documented CLI requires Node.js 18+; firmware builds use ESP-IDF 5.5. The website itself needs no build tools.

npm ci --prefix tools/lume
node tools/lume/lume.js create my-app
node tools/lume/lume.js dev my-app

Run these commands from the repository root. If auto-detection fails, add --port /dev/ttyACM0.

COUNTER WALKTHROUGH

Touch → signal → text.

The repository counter creates a signal, reads it in a Text callback, and updates it from Button.onPress. The same app also switches themes and animates its card.

Open examples/counter/app.js for the complete source. Save an edit while the CLI dev command is running to send the new app over USB.

var count = signal(0);
Text({ text: function () {
  return 'taps: ' + count();
} });
Button({ title: 'Count', onPress: function () {
  count.set(count() + 1);
} });
Current boundary: CLI first slice sends JavaScript source over USB; bytecode deployment and WiFi OTA are later work. On-device push latency is awaiting measurement.
