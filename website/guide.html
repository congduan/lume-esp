PREREQUISITES

Prepare the board and CLI.

Use the Waveshare ESP32-S3-Touch-AMOLED-2.16 with Lume firmware installed. The documented CLI requires Node.js 18+; firmware builds use ESP-IDF 5.5. The website itself needs no build tools.

npm ci --prefix tools/lume
node tools/lume/lume.js create my-app
node tools/lume/lume.js dev my-app

Run these commands from the repository root. If auto-detection fails, add --port /dev/ttyACM0.

COUNTER WALKTHROUGH

Touch → signal → text.

The repository counter creates a signal, reads it in a Text callback, and updates it from Button.onPress. The same app also switches themes and animates its card.

Open examples/counter/app.js for the complete source. Save an edit while the CLI dev command is running to send the new app over USB.

var count = signal(0);
Text({ text: function () {
  return 'taps: ' + count();
} });
Button({ title: 'Count', onPress: function () {
  count.set(count() + 1);
} });
Current boundary: USB source push, optional bytecode deployment, and HMAC-authenticated WiFi OTA are implemented. On-device push latency and radio behavior await measurement.
ROUND SCREENS

Keep content inside the round display.

For the 1.75C round display, import the optional JS shell and wrap your content in lume.ui.shell.SafeArea. A 466-pixel logical diameter gives a centered 329×329 safe square. Use the logical screen size: the Playground round preview still uses 480 logical pixels.

// In examples/your_app/app.js
import '../../runtime/shell.js';
var label = Text({ text: 'Hello', style: { width: 200, height: 40 } });
lume.ui.shell.SafeArea({ shape: 'round', size: 466,
  children: [label] });

SafeArea returns a View; its children use local coordinates inside that square. The 1.75C display and touch still need device acceptance.

ROUND-SCREEN PRACTICE

Design from the safe center outward.

SafeArea computes floor(466 / √2) = 329 logical pixels for the inscribed square; see the API contract. SafeArea API →

ClickWheel uses a circular annulus and a center button, so its gesture geometry naturally suits a round screen. Keep its center and all four tappable sectors inside the visible circle.

  • clock_round — The 480-logical-pixel dial explicitly keeps essential marks within R=205 around its clock center; it scales to the 466 panel.
  • aurora_clock — The main time sits near the center over full-screen ribbons; its date and lower status are outside a strict R=205 zone, so review them before using it as a round-screen layout.
  • watchface — Analog, activity, and goal dials use centered 300×300 or 220×220 Canvases; labels and modular cards also extend toward the square corners and need a round-screen pass.

skycombat — A full-screen 480×480 Canvas rotates the world and horizon with IMU roll while keeping the aiming reticle near the center. Its edge HUD needs repositioning for a round viewport.

Place every essential control and status item inside the inscribed safe region; decorative imagery may extend beyond it.

SHELL COMPONENT / COLORPICKER

Choose and save a color.

ColorPicker renders a 24-segment HSV hue ring, separate saturation and value strips, a preview, and CLOSE/SAVE controls in one 300×360 Canvas.

View complete example →

import '../../runtime/shell.js';

var stored = lume.storage.kv.get('demo.color');
var initial = lume.ui.shell.hexToHsv(stored) ? stored : '#40D8B0';
var selected = signal(initial);
var saved = signal(false);
var root = View({style:{x:0,y:0,width:480,height:480,background:'#07111D',scroll:'none'}});
Text({parent:root,text:'COLOR STUDIO',style:{x:122,y:4,width:236,height:24,
  fontSize:18,textAlign:'center',color:'#F2F7FB'}});
var picker = lume.ui.shell.ColorPicker({parent:root,x:90,y:25,initialHex:initial,
  onChange:function (hex) { selected.set(hex); saved.set(false); },
  onConfirm:function (hex) {
    selected.set(hex);
    if (lume.storage.kv.set('demo.color',hex) === 0) saved.set(true);
  }});
Parameter / 参数Behavior / 行为
parentParent node for the Canvas.
x, yInteger top-left coordinates; default to centered x and y=8.
initialHexA #RRGGBB value. Invalid input warns and falls back to #40D8B0.
onChange(hex)Live color; during drag, at most once per 100 ms. Pending final value is flushed on release or SAVE.
onConfirm(hex), onDismiss()SAVE reports the selected hex; CLOSE disposes the Canvas and calls onDismiss.

The example updates a signal live and writes KV only on SAVE. The Canvas also disposes on app pause.

SHELL COMPONENT / CLICKWHEEL

Turn a gesture into navigation.

ClickWheel draws an annulus and center button and translates ring pans and taps into callbacks; the app owns selection and playback state.

View complete example →

import '../../runtime/shell.js';

lume.theme.set({colors:{bg:'#08111E',primary:'#08111E',surface:'#173047',
  surfaceAlt:'#24465D',text:'#F2F7FB',textDim:'#A7BCCC',accent:'#55D7B5',
  danger:'#FF7180',success:'#55D7B5'},radius:16,spacing:0});

var tracks = [
  {name:'Paper Satellites',seconds:194}, {name:'Copper Rain',seconds:207},
  {name:'Afterglow Harbor',seconds:181}, {name:'Low Tide Signals',seconds:228},
  {name:'Glass Orchard',seconds:203}, {name:'Midnight Current',seconds:216},
  {name:'Soft Neon Road',seconds:188}, {name:'Cloudline Echo',seconds:199},
  {name:'Blue Hour Engine',seconds:211}, {name:'Quiet Frequency',seconds:176}
];
var selected = signal(0), page = signal('list'), position = signal(0), playing = signal(false);
var root = View({style:{x:0,y:0,width:480,height:480,background:'primary',scroll:'none'}});
function rotate(steps){
  if(page()==='list')selected.set(Math.max(0,Math.min(tracks.length-1,selected()+steps)));
  else position.set(Math.max(0,Math.min(tracks[selected()].seconds,position()+steps*5)));
}
function center(){if(page()==='list'){position.set(0);playing.set(true);page.set('play');}}
function outer(q){
  if(q===0){page.set('list');playing.set(false);}
  else if(q===1&&page()==='play')playing.set(!playing());
  else if((q===2||q===3)&&page()==='play'){
    selected.set((selected()+(q===2?-1:1)+tracks.length)%tracks.length);
    position.set(0);
  }
}
var wheel=lume.ui.shell.ClickWheel({parent:root,cx:240,cy:380,outerR:95,innerR:36,
  onRotate:rotate,onCenterTap:center,onOuterTap:outer});
Parameter / 参数Behavior / 行为
parentParent node for the Canvas.
cx, cy, outerR, innerRAbsolute integer screen center and radii; outerR ≥ 40 and 1 ≤ innerR < outerR.
onRotate(deltaSteps)One signed step per callback for each 1/16 turn (22.5°); clockwise is +1.
onCenterTap()Fires for a tap at radius ≤ innerR.
onOuterTap(quadrant)Cardinal sectors: 0 top, 1 right, 2 bottom, 3 left; only taps within ±22.5° of those axes fire.

The music example is UI-only; it does not output audio. Dispose the returned Canvas node to unregister gesture handlers.

SHELL COMPONENT / DIALOG

Confirm a destructive action once.

Settings replaces its former three-second arm/confirm gate with a Dialog: opening it does not reboot; only the danger button calls reboot.

View complete example →

import '../../runtime/shell.js';
var rebootNote = signal('');                 /* r143: transient reboot guard note */
function rebootNow() {
  var shell = lume.ui && lume.ui.shell;
  if (!shell || typeof shell.Dialog !== 'function') {
    rebootNote.set('reboot n/a (no dialog)');  /* stub without Dialog: never auto-reboot */
    return;
  }
  shell.Dialog({
    title: 'Reboot device?',
    message: 'Unsaved state is lost; the device restarts immediately.',
    buttons: [
      { label: 'Cancel', style: 'plain' },
      { label: 'Reboot', style: 'danger', onPress: function () {
        if (!lume.system || typeof lume.system.reboot !== 'function') {
          rebootNote.set('reboot n/a');        /* stub without the binding */
          return;
        }
        lume.system.reboot();                  /* never returns on device */
      } }
    ]
  });
}
    Button({ title: 'Reboot', onPress: rebootNow,
      style: { width: 132, height: 34, borderRadius: 8 } })
Parameter / 参数Behavior / 行为
title, messageRequired title and optional body text.
buttonsArray of {label, style?, onPress?}; style is plain, primary, or danger.
modalDefault true: top-dialog backdrop tap closes it; false: backdrop still blocks touch but does not close it.
return valueAn idempotent close function; buttons close before calling onPress.

The shell closes open dialogs on app pause. Keep the destructive binding inside the confirmed button callback, as the settings example does.

HEADLESS NETWORK

Exercise the WiFi path with esp-emu.

From the repository root, install esp-emu and the LittleFS Python dependency as described in tools/emu-net/README.md, then run the command below. The runner boots real firmware with virtual WPA2 WiFi and a loopback HTTP server, using the net_check app in LittleFS.

tools/emu-net/run.sh examples/net_check

Serial assertions use [NETCHECK] <step> <PASS|FAIL> (init, connect, IP, HTTP); completion requires [NETCHECK] ALL PASS. Logs go to artifacts/emu-net/net_check/serial.log. The recorded r144 run exits with IP FAIL after association fails; the runner is available, but virtual WiFi acceptance has not passed. Board radio and TF wiring remain unverified.
