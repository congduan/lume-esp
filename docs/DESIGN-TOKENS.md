# Lume Design Tokens — 480×480 圆屏深色 AMOLED 设计系统

> 产出方法：ui-design-father-skill 的三层 token 架构（Primitive → Semantic → Component）
> + 对 11 平台规范提取的**通用专业纪律**（Material 8dp 网格 / iOS 44pt 触区 / WCAG AA 对比度）
> + vision 实测缺陷清单反推（timer_kit 17 项缺陷为反面教材）。
> 用色与现有生态连续：accent 延续 #40D8B0 系，背景延续 #07111D 系。
> **适用**：所有 playground app 的 UI 修复与新 app 开发。UI 轮派工简报必须引用本文件。

---

## 0. 硬性红线（每个 app 开工前自检，违反 = 不可交付）

1. **圆屏安全区**：所有可交互元素 + 关键文本落在内切正方形（466 → **329px**，即 x/y ∈ [75, 405]）；装饰元素可出界但不得过圆心十字线外 220px
2. **圆角容器嵌套冲突**：app 内卡片圆角 ≤12px（外层屏幕已是大圆角，双层大圆角=不协调）
3. **触控目标 ≥48×48px**（含间距的视觉热区）
4. **对比度**：正文 ≥4.5:1，大字号（≥24px bold）≥3:1（WCAG AA）
5. **无信息冗余**：同一状态不得用两种控件表达两次（反例：STATE OFF 文字 + OFF 按钮并存）
6. **状态机驱动按钮**：同一时刻只显示当前状态合法的主按钮（反例：READY 态三个按钮 START/RESUME/RESET 全亮同色）
7. **危险操作隔离**：RESET/删除类与主操作不同色（danger 色）且位置隔开
8. **禁止字母占位图标**：图标一律 SVG 拟真或 theme accent 圆形底+白色简单字形

## 1. Primitive Tokens（原始值）

### 1.1 色板（深色 AMOLED——纯黑省电优先）

| Token | 值 | 用途 |
|---|---|---|
| `bg-0` | `#000000` | 屏幕最底（AMOLED 纯黑省电）|
| `bg-1` | `#0D1420` | app 页面底 |
| `bg-2` | `#16202E` | 卡片/面板 |
| `bg-3` | `#1F2C3D` | 卡片内嵌元素/输入框 |
| `text-hi` | `#F2F7FB` | 主文本 |
| `text-mid` | `#9EB3C6` | 次文本/标签 |
| `text-low` | `#5C7794` | 弱提示（禁用态）|
| `accent` | `#40D8B0` | 主强调（按钮/进度/选中）|
| `accent-deep` | `#117B69` | accent 的按下态/浅色模式版 |
| `danger` | `#FF6B79` | 危险操作/错误 |
| `warn` | `#FFD78E` | 警告/电量低 |
| `info` | `#5B9DF7` | 信息类 |

**规则**：一个 app 页面上 accent 出现次数 ≤3 处（按钮/进度/选中三选二）；蓝色系（info）不与 accent 混用同层级（反例：timer_kit 三个宝蓝按钮 + teal 滑条互相打架）。

### 1.2 字号阶梯（px）

| Token | 值 | 用途 |
|---|---|---|
| `fs-hud` | 14 | HUD 角标/页码 |
| `fs-label` | 16 | 次要标签/说明 |
| `fs-body` | 18 | 正文/列表行 |
| `fs-title` | 24 | 页标题 |
| `fs-display` | 48 | 主数值（时钟/倒计时/分数）|
| `fs-hero` | 96 | 单一主角数值（全屏聚焦场景专用）|

**规则**：一屏 ≤3 个字号层级；主数值一屏只有一个。

### 1.3 间距（8px 网格）

`4 / 8 / 12 / 16 / 24 / 32`（space-1~6）。页面级安全边距 = **40px**（329 安全区内再留呼吸）；组件间距 = 12/16；组内 = 8。

### 1.4 圆角

`8`（小控件）/ `12`（卡片，生态默认）/ `24`（大面板）/ `999`（胶囊按钮）。

### 1.5 触控

最小热区 `48×48`；按钮高度 48-56；滑块 thumb ≥32px 圆形（**禁止方块 thumb**——timer_kit 缺陷）。

## 2. Semantic Tokens（语义角色）

| 语义 | 组合 | 示例 |
|---|---|---|
| 主操作 | `accent` 底 + `bg-1` 字 | START/SAVE/CONFIRM |
| 次操作 | `bg-3` 底 + `text-hi` 字 | MORE/CLOSE |
| 危险操作 | `danger` 底 + 深色字，**远离主操作 ≥24px 或独立行** | RESET/DELETE |
| 禁用 | `bg-3` 底 + `text-low` 字，不响应 | 状态机不允许的动作 |
| 进度 | `accent` 填充 + `bg-3` 轨道 | 倒计时环/音量条 |
| 选中 | `accent` 底 + 深色字反白 | 列表高亮行 |
| 输入控件 vs 展示控件 | 输入控件必须带可见 thumb/边框；展示条无 thumb | 防止 timer_kit 式「两条长得一样」混淆 |

## 3. Component Tokens（组件规范摘要）

### 3.1 状态机驱动按钮（timer_kit 反例的直接纠正）
按钮集合由**当前状态唯一决定**，非法动作的按钮根本不渲染：

| 状态 | 显示的按钮 |
|---|---|
| READY | [START(accent)] |
| RUNNING | [PAUSE(次操作)] [RESET(danger，右侧隔 24px)] |
| PAUSED | [RESUME(accent)] [RESET(danger)] |
| OVER | [RESTART(accent)] |

### 3.2 径向布局优先（圆屏特性）
- 圆屏首选**中心聚焦 + 环形进度**：主数值居中（fs-display/hero），剩余量画 `ctx.arc` 环
- 线性布局仅用于列表/表单类；横向全宽元素（滑条/按钮行）宽度 ≤329px（安全区内）
- HUD 角标放在安全区四角内（x/y ∈ [80, 400]），不贴 480 边

### 3.3 状态与数字一致性
- 设置了 5 分钟倒计时 → 主显示立即 `05:00`、进度环 100%——**不得显示 00:00 + 0%**（timer_kit 缺陷：让用户误以为已结束）
- 状态字（READY/RUNNING/PAUSED）与主数值相邻、同视觉组

### 3.4 信息密度
- 一屏 ≤1 个标题 + ≤4 个信息组；BEST/LAP 等统计信息**默认隐藏**，收进次要页
- 冗余检测：写完 UI 后问「这个信息是否已在别处表达？」——是则删

---

## 4. Vision 验收量化判据（UI 轮 vision prompt 直接引用）

1. 安全区：无关键元素在 x/y ∈ [0,75]∪[405,480] 区域
2. 对比度：主文本可读（≥4.5:1 目测）
3. 层级：一屏主数值唯一
4. 按钮状态机：非法动作按钮不出现
5. 配色：accent ≤3 处、无两套蓝绿打架
6. 触区：可见可点的元素 ≥48px
7. 无裁切：文字无贴边截断、无字母残缺
